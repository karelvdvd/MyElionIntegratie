# Elion Integratie voor Home Assistant

Onofficiële Home Assistant integratie voor het uitlezen van Elion energie-installaties.

Deze integratie maakt het mogelijk om gegevens zoals batterijstatus, vermogen, verbruik en productie te visualiseren binnen Home Assistant via de Elion API.

## Geplande functies

### Basis

- [ ] Authenticatie via Elion API
- [ ] Configuratie via de Home Assistant UI
- [ ] Batterij SoC (%)
- [ ] Laadvermogen
- [ ] Ontlaadvermogen

### Energie

- [ ] PV-productie
- [ ] Netafname
- [ ] Netinjectie
- [ ] Siteverbruik

### Geavanceerd

- [ ] Historische gegevens
- [ ] Energy Dashboard ondersteuning
- [ ] Device informatie
- [ ] Diagnostics ondersteuning

## Installatie

### Via HACS

1. Open HACS
2. Voeg deze repository toe als Custom Repository
3. Kies type **Integration**
4. Installeer de integratie
5. Herstart Home Assistant
